Third-party notices for FluentFlyout Downstream

This inventory is maintained from the restored runtime dependency graph in
FluentFlyoutWPF/obj/project.assets.json. The packaging script also writes
licenses/nuget/RESOLVED-PACKAGES.txt from the exact restored package metadata
and copies any license or notice files shipped by those package archives.
The .NET runtime and Windows Desktop framework notices are copied under
licenses/dotnet/ from the installed .NET SDK/runtime used for the publish.

License expressions, authors, and project URLs below are package metadata
observed for the current downstream build. When a package archive does not
carry a separate license file, this record does not infer a different license;
the declared expression and upstream project URL remain the authoritative
reference for that dependency.

Package-provided notices

Where present in the restored package archive, the packaging script preserves
the package's original license and third-party notice files under
licenses/nuget/. In particular, the current graph includes package-provided
notices for CommunityToolkit.Mvvm, Microsoft.Extensions.Logging.Abstractions,
unchihugo.WPF-UI, and WPF-UI. The generated resolved-package report lists the
exact files copied for each package.

.NET runtime notices

The self-contained publish includes the .NET runtime and Windows Desktop
framework. Their license and third-party notice files are preserved under
licenses/dotnet/LICENSE.txt and licenses/dotnet/ThirdPartyNotices.txt.
